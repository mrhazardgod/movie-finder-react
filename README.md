# MovieFinder

A movie search application built with React, TypeScript, Vite and React Router.  
The app allows users to search for movies, view detailed information, filter results, and save favorite movies.

## Features

- Search movies by title
- View movie details
- Add movies to favorites
- Remove movies from favorites
- Save favorites in localStorage
- Client-side routing with React Router
- Loading states
- Error and empty states
- Responsive user interface

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- OMDb API
- CSS
- localStorage

## Project Goal

This project was created to practice building frontend applications with React and TypeScript.  
The main focus was on API integration, routing, reusable components, state management, localStorage, and handling loading, error, and empty states.

## What I Learned

- Working with React and TypeScript
- Creating reusable components
- Using React Router for navigation
- Fetching and displaying data from an external API
- Managing favorites with localStorage
- Handling loading, error, and empty UI states
